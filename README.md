# Пост без разрыва

Браузерный редактор поста для Telegram: помогает проверить длину подписи к фото **до отправки** и собрать
две копии текста.

## Что это

- **Один самостоятельный HTML-файл.** Весь CSS и JavaScript встроены в `index.html`; страница открывается
  прямо в браузере, в том числе с диска и без интернета. Внешних загрузок (шрифтов, скриптов, картинок,
  аналитики) нет.
- **Никаких серверных отправок.** Введённый текст никуда не уходит: всё считается локально в браузере.
- **Вставка — обычным текстом.** При вставке из чужого документа форматирование и скрытые ссылки
  не сохраняются. Оформление и адреса добавляются панелью инструмента: выделить текст → «жирный»,
  «курсив» или «Ссылка».
- **Два экспорта.** «Обычный текст с адресами» — полные URL для ручной вставки; «HTML для Bot API» —
  оформление для отправки с `parse_mode=HTML`.
- **Ничего не публикует и не сокращает.** Редактор только считает длину и предупреждает о переборе;
  текст сокращает автор.

## Что важно про лимиты

1 024 и 4 096 — текущие профили Bot API для подписи к фото и обычного сообщения. У других клиентов
и аккаунтов Telegram ограничения могут отличаться, так что это не универсальная гарантия.
